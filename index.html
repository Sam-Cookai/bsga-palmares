Base de données

Sauvegardez, chargez ou réinitialisez la base locale
Publier la base en ligne (GitHub)

Pour que tous les appareils (ordinateurs, téléphones) voient la même base :

  1. Cliquez sur le bouton ci-dessous : il génère le fichier data.js avec tous les résultats et les dates de naissance de cet appareil.
  2. Sur github.com/Sam-Cookai/bsga-palmares : Add file → Upload files, déposez data.js, puis Commit changes (il remplace l'ancien).
  3. Après 1 à 2 minutes, chaque appareil qui ouvre l'application en ligne ajoute automatiquement les résultats qui lui manquent (rien n'est supprimé).
Sauvegarder la base

L'application fonctionne entièrement dans ce fichier HTML : les données vivent en mémoire et dans le stockage du navigateur. Pour les conserver durablement (ou les transférer sur un autre ordinateur), exportez-les régulièrement dans un fichier donnees.json.

Charger une base

Chargez un fichier donnees.json précédemment exporté pour remplacer entièrement la base actuelle.

Statistiques de la base
Tables de cotation FFA

Importez les tables de cotation FFA (PDF) pour afficher le niveau de chaque athlète dans sa fiche et dans le tableau de bord. Chaque table correspond à une catégorie d'âge.

Zone de danger

Réinitialiser efface tous les résultats actuellement en mémoire et dans le stockage du navigateur. Pensez à exporter une sauvegarde avant.
